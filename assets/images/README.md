# Artwork

The images that the game shows as Background artwork, as
[Background artwork](../../docs/specs/design/ui/visual-design.md#background-artwork) in Visual Design describes; that
section also names the Detail view that shows each image.

Each image was generated by an AI image model. The table maps each file to what it shows and its source.

| File                              | Shows                                                               | Source              |
| --------------------------------- | ------------------------------------------------------------------- | ------------------- |
| `chatgpt-agents-i2.png`           | Agents in an equipment room, before a wall of personnel dossiers.   | ChatGPT             |
| `v03ai-nano21-command-center.jpg` | Operators in a dark command center, before a wall map of the Earth. | Nano 2.1, via v03ai |

## Image from ChatGPT

`chatgpt-agents-i2.png` is from a ChatGPT session of the Game designer.

## Image from Nano 2.1

`v03ai-nano21-command-center.jpg` is from Nano 2.1, made in a [v03ai](https://v03ai.com/) session of the Game
designer.
