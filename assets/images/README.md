# Artwork

The images that the game shows as Background artwork, as [Background artwork](../../docs/specs/design/ui/visual-design.md#background-artwork) in Visual Design describes; the BackgroundArtwork GDRs in `content/visual-design/background_artworks.yaml` name the Detail view that shows each image.

Each image was generated by an AI image model. The table maps each file to what it shows and its source. A suffix such as `-i2` in a file name usually marks the iteration of the image that the Game designer kept, e.g. `-i2` for iteration 2.

| File | Shows | Source |
| --- | --- | --- |
| `chatgpt-agents-i2.png` | Agents in an equipment room, before a wall of personnel dossiers. | ChatGPT |
| `chatgpt-investigation-i3.png` | An agent in a raincoat, a radio in hand, watching a crowded, neon-lit street in the rain from behind a pillar. | ChatGPT |
| `v03ai-nano21-command-center.jpg` | Operators in a dark command center, before a wall map of the Earth, at 5483 × 3060 px, from an upscaled image kept outside the repository. | Nano 2.1, via v03ai |

## Images from ChatGPT

`chatgpt-agents-i2.png` and `chatgpt-investigation-i3.png` are from ChatGPT sessions of the Game designer.

## Image from Nano 2.1

`v03ai-nano21-command-center.jpg` is from Nano 2.1, made in a [v03ai](https://v03ai.com/) session of the Game designer.
