# Soundtrack

The music tracks the game plays, as the [Music](../../docs/specs/design/ui/music.md#soundtrack) specification
describes. Each `.opus` or `.mp3` file is one track, and its title is its file name without the extension, with
underscores shown as spaces.

## Tracks from ElevenLabs

All the `.opus` files are from [ElevenLabs](https://elevenlabs.io/):

- Abyss Protocol
- Abyssal Tactical Drift
- Beneath the Grid
- Black Orbit Watch
- Depth Signal
- Silent Contact
- Silent Contact Protocol
- Silent Hostile Sector
- Silent Threat Protocol
- Subsurface Directive
- Unknown Contact
- Unseen Sector
- Unseen Threat Protocol

## Tracks from Suno v5

The `.mp3` files are from Suno v5, made via [v03ai](https://v03ai.com/), which cannot export Ogg Opus:

- v03AI UFO 1
- v03AI UFO 2
