# Sounds

The short sounds the game plays in answer to the Player, as the [Sounds](../../docs/specs/design/ui/sounds.md#sound-set) specification describes. Each file is one Sound, and its Sound name is its file name without the extension, e.g. `main-click.wav` is the Sound named `main-click`. The specification says when each Sound plays.

Each AI-generated file was renamed from the file name its source gave it. The table maps each file to that original file name.

| File                           | Original file name                          |
| ------------------------------ | ------------------------------------------- |
| `main-click.wav`               | `Short,_smooth_electr_#2-1794963739351.wav` |
| `go-back-click.wav`            | `Short,_smooth_electr_#1-1794963755026.wav` |
| `interesting-turn-summary.wav` | `Short,_mysterious_el_#1-1794963918107.wav` |

## Source files

Every file of this directory is a copy of the file of the same name under `projects\ufo_game\sounds\selected_for_ui` in the designer's personal OneDrive, i.e. `OneDrive\personal\projects\ufo_game\sounds\selected_for_ui`, e.g. `main-click.wav` is a copy of `selected_for_ui\main-click.wav` there. All `projects\ufo_game` paths below are in the same OneDrive folder.

`main-click.wav`, `go-back-click.wav`, and `interesting-turn-summary.wav` were generated by AI. The original files, together with candidates that were not chosen, are backed up under `projects\ufo_game\sounds\ai_gen` and managed with SoundQ from Pro Sound Effects.

`select-click.mp3` was not generated by AI: it was made from the UI click sounds under `projects\ufo_game\sounds\other\sfx_ui_click`, which come from OpenGameArt, under <https://opengameart.org/content/ui-click-sounds-sci-fi>.

Some files were post-processed in Audacity. Each such file was exported from the Audacity project of the same name with the extension `.aup4` next to it under `projects\ufo_game\sounds\selected_for_ui`, e.g. `main-click.wav` from `main-click.aup4` and `select-click.mp3` from `select-click.aup4`. Further provenance of every sound, including the post-processing, is given in `projects\ufo_game\sounds\README.md`.
