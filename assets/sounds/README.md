# Sounds

The short sounds the game plays in answer to the Player, as the [Sounds](../../docs/specs/design/ui/sounds.md#sound-set) specification describes. Each file is one Sound, and its Sound name is its file name without the extension, e.g. `main-click.wav` is the Sound named `main-click`. The specification says when each Sound plays.

Each file was renamed from the file name its source gave it. The table maps each file to that original file name.

| File                           | Original file name                          |
| ------------------------------ | ------------------------------------------- |
| `main-click.wav`               | `Short,_smooth_electr_#2-1794963739351.wav` |
| `go-back-click.wav`            | `Short,_smooth_electr_#1-1794963755026.wav` |
| `interesting-turn-summary.wav` | `Short,_mysterious_el_#1-1794963918107.wav` |

## Source files

The sounds were generated by AI. The original files, together with candidates that were not chosen, are backed up under `projects\ufo_game\sounds\ai_gen` and managed with SoundQ from Pro Sound Effects.

Some files were post-processed in Audacity after generation. `main-click.wav` is a copy of `projects\ufo_game\sounds\main-click-fixed.wav`, exported from the Audacity project `main-click.aup4` next to it. Further provenance of every sound, including the post-processing, is given in `projects\ufo_game\sounds\README.md`.
